# 公网与浏览器验收 · 2026-11-17

## 已通过的真实公网流程

运行 `npm run host:ssh -- --port 3005 --database data/public-acceptance.sqlite`，房主浏览器访问本机服务，
朋友浏览器访问 localhost.run 分配的临时 HTTPS 地址。使用安装的 Microsoft Edge（headless）、
两个隔离 BrowserContext；朋友端实际 WebSocket 主机名与公网域名一致，没有将请求改写成本机连接。

默认原创几何主题完成 **95 次行动，10 类行动，3.6 分钟，页面脚本错误 0**：

- 页面创建 Asuka 房间、填写邀请码加入 Sinji；双方显示相同房间和局面版本。
- 盲预留后，对手收到的预留内容仍为 `null`。
- 朋友端真正切断浏览器网络；页面显示重连中，棋盘操作禁用。
- 恢复网络后自动重连；刷新页面仍回到原座位、原局面。
- 导出重连凭证，关闭朋友浏览器环境，在全新环境中导入并继续对局。
- 通过页面控件执行预留、特权、拿取、购买、补盘、选色、奖励筹码、王室、窃取、归还。
- 全程等待两端版本一致；双方确认相同胜者；终局打开现有胜率回放。
- 查看 1600×1000 与 1366×768 截图；检查资源图标和数字不重叠。

驱动只使用玩家收到的可见信息选择合法动作，每步通过实际页面点击提交。
没有直接修改游戏状态，也没有使用测试后门。胜率分析只验收终局页面可用，未将本次测试声称为 AI 精度评测。

## 本次发现并修正

- Cloudflare 下载不再依赖匿名 GitHub API 额度；固定官方版本及 SHA-256，流式下载并支持断点续传。
- 隧道只有注册成功才提示分享，90 秒未就绪就清理退出；新增已核验官方主机指纹的 SSH 备用入口。
- 支持临时 SSH 域名轮换，只允许当前确切公网 Origin；提供命令行端口、存档路径参数。
- JS/CSS 等小文本响应支持 gzip；静态文件声明长度，图片支持缓存与 ETag；断开的文件传输及时停止。
- 构建时串行生成 WebP 副本，原始 PNG 保留。75 张本机主题图从 138.4 MiB 降至 2.7 MiB。
- 修复联机「记录」按钮文字换行、整局表现按钮缺少主题样式的问题。
- 增加可重复运行的浏览器验收脚本、隧道解析及压缩/缓存/图片格式协商回归检查。

## 验证边界

本次公网链路是真实第三方 HTTPS/WSS 转发，但两个浏览器在同一台电脑上运行；尚未使用朋友的异地物理设备。
Cloudflare 能申请临时网址，但所在网络到隧道节点的连接失败，因此 **Cloudflare 公网验收未通过**。
备用 SSH 链路完成上述默认主题整局验收，但 EVA 图片即使缩小后仍发生传输超时/截断，
因此 **EVA 公网完整视觉体验尚未通过**；不能把默认主题结果推广成所有主题、地区和网络都稳定。

免费域名可能轮换或被服务方回收，没有可用性保证。续玩前保存重连凭证，切换网址后导入恢复座位。
